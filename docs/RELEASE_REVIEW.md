## AI 연동 계약 (후속 개발)

입력은 확정 계산 JSON, 승인된 해석 근거 목록, 사용자 조회 목적이다. 출력은 문장별 `rule_id`, `evidence_id`, `period_start`, `period_end`, `uncertainty`를 포함하는 구조로 제한한다. 원국·기간 간지·대운은 AI가 재계산하거나 수정하지 못한다. 검수 전에는 길흉 종합과 사건 예측을 생성하지 않는다.

AI의 출력 문체가 좋아졌다는 이유로 계산 품질이 좋아졌다고 평가하지 않는다. 연간·월간·일간의 모순, 근거 누락, 미확정 입력에 대한 과도한 확신을 별도로 검증한다.

## 보관 및 재현성

사용자 입력은 브라우저 메모리에만 둔다. 결과 JSON을 사용자가 내려받을 때만 출생정보가 파일에 포함된다. 재현에는 엔진·해석 규칙·절기 데이터·시간대 데이터 버전과 원래 입력을 사용한다. 저장형 서비스로 확장할 때는 별도 보관·삭제 정책을 정한다.

## v0.1.2 화면 확인

DOM 환경에서 결과 버튼, 설명 우선 순서, 상세 계산 기본 접힘, 세 생활 영역, 연·월·일 전환, 출생일 미확정 시 설명 보류, 설명을 포함한 JSON 내려받기, 초기화를 확인했습니다. 이 검사는 실제 브라우저의 레이아웃·인쇄·실기기 검수를 대신하지 않습니다.

## v0.1.4 분야별 결과

돈·건강·직장·대인관계·애정과 주의사항을 표시합니다. 문체를 직접적으로 바꾸었으며 예측 정확도나 전문가 검수 상태가 개선되었다고 주장하지 않습니다. 건강은 명식과 무관하게 동일한 일반 안내를 표시합니다. 애정은 새 인연 / 연인·배우자가 있는 경우를 나누고 현재 관계를 추정하지 않습니다. 결과 JSON의 중첩 문장을 외부에서 수정해도 다른 조회를 오염시키지 않는지 검증했습니다. 실제 브라우저 시각 QA는 이번 변경에서 수행하지 않았습니다.

## v0.1.7 연간 월별 보기

연간 결과 화면은 12개월의 단독 월간 계산을 모아 표시합니다. 각 월의 계산 원값과 설명을 결과 JSON에 함께 보존하며, 생일 전 월은 자리만 표시하고 풀이하지 않습니다. 월별 비교·윤년·연말·미확정 입력 테스트를 추가했습니다. 실제 브라우저 레이아웃과 인쇄 실기기 QA는 이번 변경에서 수행하지 않았습니다.

## v0.1.8 분야별 운세 탭

돈·직장·대인관계·애정을 탭으로 전환하고 요약·공통 주의사항을 접었습니다. 각 월의 풀이와 계산 규칙은 유지합니다. 입력 안내는 v0.1.9부터 제목 옆 참고사항으로 제공하며, 인쇄는 전체 분야를 포함하고 화면 상태를 복원합니다.

## v0.1.9 참고사항 분리

출생정보에 따른 풀이 범위 안내를 제목 옆 `※ 참고`에 모았습니다. 마우스·키보드·터치로 열 수 있으며, 결과 보류와 출생시간 확인 필요 표시는 유지합니다. 운세 계산과 안내 원문은 변경하지 않았습니다.


## v0.1.10 서술형 풀이

총론과 네 분야를 존댓말 문단으로 재작성하고 전체 보기를 기본값으로 변경했습니다. 날짜 경계와 계산 엔진은 유지합니다. 기존 44개 자동 테스트와 빌드 검증을 통과했으며, 결과 HTML의 선택 상태와 제목 참조도 확인했습니다. 실제 브라우저 시각·인쇄 검수는 미수행입니다. `reading-preview.html`은 가상 출생정보로 생성한 고정 예시입니다. 전문가 검수 및 종합 길흉·AI 연동 상태는 기존과 같습니다.


## v0.2.0 조건 조합형 해석

- 원국의 확정 십성 군 구성, 연·월의 배경, 조회 지지 본기, 출생 지지와의 관계, 활성 대운을 본문에 반영합니다.
- 지지 관계의 혼합 조건, 입력 미확정의 제외, 문장별 근거와 대운 변경 구간을 자동 검증합니다.
- 시간 선택 목록 13개는 하루의 1440분을 중복·누락 없이 포함하며, 야자시의 끝은 다음 날을 포함하지 않습니다.
- 시간대 입력은 범위 입력으로 처리하고 기존 표준시·지방평균태양시 기준을 유지합니다.
- 실제 브라우저 시각·실기기·인쇄 검수와 전문가 해석 검수는 수행하지 않았습니다.
- 규칙 명세는 `INTERPRETATION_RULES.md`를 참조합니다. 생성형 AI는 연결하지 않았으며 이번 확장에 필요하지 않습니다.
