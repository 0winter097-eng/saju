# 공개 소프트웨어와 자료

| 구성 | 버전 | 라이선스 / 출처 |
|---|---|---|
| Astronomy Engine | 2.1.19 | MIT, Don Cross. 라이선스 전문은 `dist/vendor/astronomy.js` 상단 포함. https://github.com/cosinekitty/astronomy |
| korean-lunar-calendar | 0.4.0 | MIT, Jinil Lee. `dist/vendor/KOREAN-LUNAR-LICENSE.txt`. https://github.com/usingsky/korean_lunar_calendar_js |
| IANA Asia/Seoul 규칙 부분집합 | tzdb 2025b | Public domain. https://data.iana.org/time-zones/tzdb-2025b/asia |

원본 npm 배포본에서 추출해 포함했다. 외부 CDN을 실행 중 참조하지 않는다. 라이브러리의 한국천문연구원 자료 활용 설명은 제작자의 설명이며 본 프로그램의 공식 인증을 뜻하지 않는다.

절기표는 Astronomy Engine으로 생성했으며 한국천문연구원의 전체 공식 절기표를 복제한 자료가 아니다. 공개 사실 대조 사례의 출처는 `tests/fixtures.json`에 명시했다.
