# 조건 조합형 해석 기준

- 작성일: 2026-09-09
- 앱: v0.2.0 / 문장: NARRATIVE-KO-2 / 확장 규칙: COMPOSITE-KO-1
- 상태: 개발 검토용. 전문가 검수 전이며 미래 사건의 예측 성능을 검증한 규칙이 아닙니다.

## 동작 방식

사주 계산 결과에서 조건을 추출하고, 해당 조건에 연결된 문장을 선택하여 총론과 네 분야의 풀이를 조합합니다. 실행 중 생성형 AI·외부 해석 API·무작위 문장 선택을 사용하지 않습니다. 동일한 입력과 조회 기간에는 동일한 계산값·문장·규칙 근거가 나옵니다.

기존의 조회 십성 10개 문장에 아래 요소를 추가했습니다. 문장을 추가하는 조건과 표면 개수를 사용하는 기준은 이 프로젝트에서 명시적으로 정한 편집 규칙입니다. 고전이나 다른 서비스의 검수된 원문을 이식한 것으로 표현하지 않습니다.

| 규칙 | 조건과 사용하는 값 | 본문 반영 |
|---|---|---|
| TG-1 | 출생 일간과 조회 천간의 십성 | 기존 총론·재물·직장·관계·애정의 기본 문단 |
| NATAL-GROUP-* | 확정된 연·월·시 천간과 연·월·일·시 지지 본기의 십성을 5개 군으로 집계. 기준인 일간은 제외 | 단독 최다이며 2개 이상인 군이 있을 때 출생 구성별 설명 |
| NATAL-PERIOD-REPEAT / SHIFT | 출생 구성에서 선택한 군과 조회 십성 군 비교 | 같은 주제의 반복 또는 다른 주제를 함께 챙기는 문단 |
| LAYER-year | 월간·일간 조회에 해당 구간의 연간지 추가 | 한 해의 배경과 현재 기간의 주제를 함께 설명 |
| LAYER-month | 일간 조회에 해당 구간의 월간지 추가 | 이달의 배경과 일간의 주제를 함께 설명 |
| LAYER-daewoon | 확정 가능한 대운 일정 중 해당 구간에서 활성인 대운 | 장기 흐름의 주제 추가. 시작 전·미확정은 추가하지 않음 |
| TARGET-BRANCH-MAIN | 조회 지지 본기의 십성 군이 조회 천간과 다름 | 표현된 주제 외에 실행 과정에서 보완할 주제 |
| RELATION-분야-* | 조회 지지와 확정된 출생 연·월·일·시 지지의 육합·충·반복 | 관계에 맞춘 설명. 육합과 충이 함께 있으면 혼합 문장 |

십성 군은 비견·겁재 / 식신·상관 / 편재·정재 / 편관·정관 / 편인·정인입니다. 구성의 개수는 강약·길흉·신강약 점수로 사용하지 않습니다. 동률이거나 2개 미만이면 임의로 우세한 군을 고르지 않습니다. 누락된 기둥은 0개의 특정 오행으로 해석하지 않고 집계에서 제외합니다.

## 분야 연결과 중복 처리

- 출생 구성과 조회 천간의 기본 설명은 모든 분야에 반영합니다.
- 배경 기간과 조회 지지 본기: 비겁은 재물·대인관계·애정, 식상은 직장·대인관계·애정, 재성은 재물·직장, 관성은 직장·재물·애정, 인성은 직장·대인관계에 부가 설명을 연결합니다.
- 지지 관계: 총론에는 전체를 반영하고, 연지는 대인관계, 월지는 재물·직장, 일지는 대인관계·애정, 시지는 직장에 연결합니다. 이는 이 앱의 문장 배치 기준이며 해당 위치만으로 실제 가족·직업·미래 사건을 확정하지 않습니다.
- 육합과 충이 함께 있으면 혼합 설명을 사용합니다. 그렇지 않으면 충 → 육합 → 반복 순서로 표시 문장을 고르며 계산된 관계는 모두 근거에 남깁니다. 이 순서는 길흉 점수가 아닌 표시 우선순위입니다.
- 연·월·대운의 같은 십성 군이 반복되면 같은 설명을 늘리지 않고 근거만 유지합니다.
- 규칙의 `priority`는 설명 분류용 메타데이터이며 운세 점수나 강약 가중치가 아닙니다. 문단 순서는 기본 설명 → 출생 구성 → 구성과 기간 비교 → 연·월·대운 → 조회 본기 → 지지 관계 → 기본 주의사항입니다.

## 기간과 불확실성

연간은 조회 연간지를, 월간은 월간지를, 일간은 일간지를 기본 대상으로 사용합니다. 월·연간 계산 행의 임의 대표 순간 일진을 한 달·한 해 전체의 일진으로 해석하지 않습니다.

본문은 기본 십성과 확장 문맥이 모두 같은 인접 구간만 합칩니다. 절입이나 대운 변경으로 설명에 필요한 값이 바뀌면 적용 기간을 구분합니다. 출생 일간이 미확정이면 개인별 풀이를 보류합니다. 다른 기둥만 미확정이면 확정된 기둥만 사용하고 제외 항목을 결과에 기록합니다.

## 태어난 시간 선택

첨부 이미지의 시간 구간 13개를 그대로 입력 선택지로 제공합니다. 조자시는 00:00~01:30, 이후 구간은 01:31~03:30부터 두 시간씩, 야자시는 23:31~24:00입니다. 시·분 단위 입력에서 각 범위의 종료 분 전체를 포함합니다. 야자시의 24:00은 해당 날짜 끝을 뜻하며 내부 범위는 23:59:59.999까지입니다. 다음 날 00:00을 해당 출생일에 섞지 않습니다.

이것은 **시간대 입력 UI의 구간**입니다. 기존 엔진의 자시 23:00~00:59 기준이나 경도 보정 규칙을 30분 일괄 보정으로 바꾸지 않습니다. 선택 항목의 지지 이름을 시주로 강제하지 않고 전체 범위를 계산합니다. 따라서 표준시 경계 등을 가로지르면 시주가 둘 이상 나올 수 있습니다. 시간 모름·정확한 시각·직접 시간 범위를 함께 지원합니다.

범위 입력의 대운 시작을 임의의 중간 시각으로 확정하지 않습니다. 정확한 시·분을 입력했고 기존 대운 산정 조건을 충족한 경우에만 대운 설명을 추가합니다. 서머타임 중복·누락 및 지방평균태양시의 날짜 변경은 기존 엔진에 따라 처리합니다.

## 결과 JSON

- `plainReading.rulesVersion`: 확장 규칙 버전
- `plainReading.profile`: 확인 가능한 원국 십성 군의 구성, 집계값, 제외 기둥
- `segments[].context`: 조회 기본 관계, 지지 본기, 배경 연·월·대운, 지지 관계
- `segments[].rules`: 적용 규칙 ID와 원시 계산 근거, 중복 설명 생략 여부
- `segments[].paragraphEvidence`: 화면에 표시한 문단별 규칙 연결
- `segments[].evidencePeriod`: 모든 문단에 적용되는 시작·끝 시각과 원본 행 번호
- `input.timeBand`: 사용자가 선택한 시간 구간과 범위 정의 버전

연간 결과의 `annualReading.months[].reading`에도 동일한 근거 구조가 포함됩니다.

## 미구현 범위

용신·격국·신강약, 계절·통근 가중치를 포함한 강약 판정, 합화, 형·파·해·신살·십이운성, 미래의 수입·결혼·승진·질병·사건 확정은 추가하지 않았습니다. 이를 확장하려면 적용 학파와 검수 사례를 먼저 정해야 합니다. 시간 범위 입력의 대운 시작 범위 산정 역시 기존 미구현 상태입니다.
