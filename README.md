# 사주연구실

출생정보와 조회 기간을 바탕으로 계산 근거·입력 불확실성·검증 상태를 함께 확인하는 정적 웹앱입니다.

**상태: v0.1.9 개발 검토 버전. 전문가 승인 또는 미래 예측 성능 검증을 마친 제품이 아닙니다.**

## 실행

Node.js 22 이상으로 테스트하고 Python으로 로컬 웹 서버를 실행할 수 있습니다. 브라우저의 모듈 로딩 때문에 `index.html`을 파일 더블클릭으로 열지 마세요.

```bash
npm test
npm run build
python -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`에 접속합니다. 외부 의존 라이브러리는 `dist/vendor`에 버전을 고정해 포함했으므로 앱 실행 및 테스트에 npm 설치나 API 키가 필요하지 않습니다.

## 구현 범위

- 국내 출생, 양력 환산 후 1970-01-01~2050-12-31
- 양력·한국 음력·평달·윤달 검증, 음력 2월 30일 등 지원
- 출생시간 시·분 / 같은 날 시간 범위 / 시간 미상
- 출생기록·가족 기억·확인 불가의 근거 구분
- 국내 도시 선택 또는 경도 직접 입력, 표준시 또는 지방평균태양시
- 1987·1988년 국내 서머타임과 중복·누락 시각 처리
- 입춘 연주, 12절 월주, 자정/23시 선택 일주·시주
- 연간·월간·일간 조회와 절입·대운 변경 구간 분리
- 기초 십성, 지장간, 표면 오행 집계, 일지와 조회 지지의 육합·충·반복
- 계산 후보 비교, 근거·버전 표시, JSON 내려받기, 인쇄
- 브라우저 메모리에서만 입력 처리. 분석 API 호출·자동 저장 없음
- GitHub Actions 자동 테스트 및 GitHub Pages 배포 설정

## 화면 사용

1. 출생정보를 입력하거나 **가상 예시 결과 바로 보기**를 누릅니다.
2. 보고 싶은 연도·월·날짜를 고릅니다. 예: `2027년` 연간 조회.
3. **내 사주 결과 보기** 또는 **운세 결과 보기**를 누릅니다.
4. 쉬운 요약 → 돈 / 직장 / 대인관계 / 애정 → 특히 조심할 점을 읽습니다.
5. 한자 명식, 오행과 계산 근거는 **상세 계산 보기**를 펼쳐 확인합니다. 출생시간이 불확실하면 입력 안내를 먼저 확인합니다.
6. **계산 기준**, **검증 현황**에서 적용 규칙·출처·남은 검증을 확인합니다.

## GitHub 배포

사용자가 제공한 Actions 성공 화면에서 `0winter097-eng/saju`의 기존 GitHub Pages 배포를 확인했습니다. 아래 절차는 새 저장소를 만들 때의 안내입니다. 기존 사이트 업데이트는 ZIP 안의 `saju-reference` 폴더 내용물을 저장소 루트에 덮어쓴 뒤 main에 커밋하면 됩니다. 이 패키지를 다운로드하는 것만으로 GitHub 사이트가 갱신되지는 않습니다.

1. 사용 권한이 있는 사주 프로젝트 전용 저장소를 준비합니다. 법인 업무라면 승인된 법인 저장소를 사용합니다.
2. 이 폴더의 내용을 저장소 루트에 올립니다. `.github/workflows/pages.yml`도 반드시 포함합니다.
3. 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택합니다.
4. `main` 브랜치에 반영하면 `Saju Verify and Deploy`가 실행됩니다.
5. 테스트와 파일 검증이 성공한 경우에만 `dist`를 배포합니다. PR에서는 검증만 수행합니다.
6. Actions의 배포 작업에서 접속 주소를 확인합니다.

이 자동 배포는 화면에 **검토 버전**임을 표시한 앱을 배포합니다. 상용·정식 서비스 전에는 `docs/RELEASE_REVIEW.md`의 미완료 사항을 해결해야 합니다. 저장소 공개 범위와 Pages 접속 공개 범위는 별도 확인해야 하며, 정적 사이트 코드와 내장 해석 규칙은 이용자의 브라우저에 전달됩니다. AI API 비밀키를 정적 파일에 넣지 마세요.

공식 배포 참고: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## 제한

현재 기본 풀이 문장은 전문가 미검수입니다. 용신·격국·신강약·합화·직업/재물/건강의 종합 길흉·사건 확정은 구현하지 않았습니다. 생성형 AI도 연결하지 않았습니다. 외부 풀이를 생성하는 AI를 추가하려면 검수 자료와 별도 서버가 필요합니다.

절기표는 천문 계산값입니다. 공식 역서 전체 대조가 끝나지 않았으며, 절입 전후 30분은 보수적 확인 구간으로 분류합니다. 이 범위는 입증된 오차 상한이 아닙니다. 대운의 365.2425일 연속 환산은 명시적으로 선택한 개발 기준이므로 달력식 환산을 쓰는 만세력과 차이가 날 수 있습니다.

테스트 통과율은 운세 적중률이 아닙니다. 자세한 내용은 계산 기준서와 검토 체크리스트를 참고하세요.

## 결과 표시 개선 (2026-09-09)

결과 버튼을 누르면 운세 조회 탭을 열고 결과로 이동합니다. 생년월일은 숫자 8자리·하이픈·점·슬래시를 지원합니다. 입력 오류 시 안내로 이동하며, 기능 로딩 실패 시 다시 불러오기 버튼을 제공합니다. 일반 클릭 전에 기능 준비 상태를 확인하며 출생정보가 폼 기본 동작으로 전송되지 않도록 차단합니다.

## 쉬운 설명 화면 (v0.1.2)

기존 TG-1 관계를 한글 요약, 생활 영역별 참고 설명, 실천 질문으로 번역했습니다. 날짜 경계와 계산식은 변경하지 않았습니다. 동일한 기본 관계가 이어지는 구간은 묶고, 원본 행 번호·적용 기간·설명 버전을 JSON에 함께 넣습니다. 일반 설명은 10년 단위 대운을 종합하지 않습니다. 계산 상세는 기본적으로 접혀 있으며 인쇄에는 쉬운 설명이 표시됩니다. 전문가 해석 검수와 미래 예측 검증 상태는 이전과 같습니다.

## 출생지역 목록 표시 수정 (v0.1.3)

출생지역 14개 항목(직접 경도 입력 포함)과 조회 월 12개 항목을 HTML에 미리 포함했습니다. 계산 모듈을 불러오기 전이나 로딩 실패 시에도 목록이 비지 않으며, 로딩 전에 선택한 값을 초기화하지 않습니다. 정적 검증에서 지역 목록과 계산 엔진의 지역 정보가 일치하는지 확인합니다. 파일 더블클릭으로 열어 계산 기능을 불러오지 못하면 로컬 서버 접속 방법을 안내합니다.

## 명확한 분야별 설명 (v0.1.4)

결과를 돈·건강·직장·대인관계·애정 순서로 구성합니다. 각 분야는 핵심 내용·할 일·조심할 점을 직접적인 문장으로 표시하며, 애정은 새 인연과 연인·배우자가 있는 경우를 나눕니다. 특히 조심할 점을 별도로 모았습니다. 기초 TG-1 관계를 생활 조언으로 번역한 것이며 좋음/나쁨 점수나 수입·질병·승진·만남의 발생 예측을 추가하지 않았습니다. 건강은 모든 출생정보에 동일하게 판단 불가와 일반 안내를 표시하고 MedlinePlus의 검사 결과 안내를 연결합니다.

개인별 기준이 미확정이면 네 생활 분야의 설명을 보류하고 건강의 일반 안내만 유지합니다. 적용 기간·원본 계산 행·문장 버전(PLAIN-KO-2)은 결과 JSON에 포함됩니다.

## 건강 항목 제거 (v0.1.5)

결과 화면과 내려받는 설명 JSON에서 건강 항목과 일반 의료 안내를 제거했습니다. 현재 결과는 돈·직장·대인관계·애정 네 분야이며, 각 분야의 할 일과 조심할 점은 유지합니다. PC에서는 네 카드를 2열로 배치합니다. 설명 버전은 PLAIN-KO-3입니다.

## 풀이 말투 개선 (v0.1.6)

전체 요약과 돈·직장·대인관계·애정, 주의사항 문장을 친근한 해라체로 다듬었습니다. 단순한 어미 치환 대신 문장을 다시 썼으며 기초 관계·기간 구분·조언 주제는 유지했습니다. 입력 오류와 불확실성 안내는 존댓말을 유지합니다. 설명 버전은 PLAIN-KO-4입니다.

## 연간 운세의 월별 보기 (v0.1.7)

연간 조회는 1월부터 12월까지 표시합니다. 각 달을 펼치면 해당 달의 요약과 돈·직장·대인관계·애정, 주의사항을 볼 수 있습니다. 월 선택 버튼으로 원하는 달로 이동할 수 있으며, 처음에는 첫 조회 가능 월을 펼칩니다. 인쇄 시 12개월을 모두 펼쳐 출력합니다.

연간 문장을 반복하지 않고 각 달에 월간 조회 함수를 적용합니다. 달 안의 절입 경계, 출생시간 불확실성, 출생 전 기간 제외 기준도 월간 조회와 같습니다. JSON의 annualReading.months에는 월별 계산 결과와 문장 및 근거를 함께 담습니다. 기존 연간 계산 원값은 상세 계산과 period에 유지합니다.

## 분야별 운세 탭 (v0.1.8)

- 돈·직장·대인관계·애정 중 선택한 분야만 표시합니다. 각 분야의 조언과 조심할 점은 함께 읽을 수 있습니다.
- 연간 운세의 각 월에서도 분야를 선택할 수 있습니다. 월별 탭은 독립적으로 작동하며, 새로 조회할 때는 마지막으로 선택한 분야로 시작합니다.
- 전체 요약과 공통 주의사항은 접힌 항목에서 펼쳐 봅니다. 입력정보에 관한 안내는 결과 제목 옆 ※ 참고에서 확인할 수 있습니다.
- 방향키·Home·End로 분야를 전환할 수 있습니다. 인쇄할 때는 모든 분야와 전체 요약을 포함하고 인쇄 종료 후 화면 선택 상태를 복원합니다. JSON에는 모든 분야를 보존합니다.

## 참고사항 표시 (v0.1.9)

출생시간 불확실성과 대운 계산 제한 안내를 결과 제목 옆의 작은 `※ 참고`로 옮겼습니다. 마우스 올리기·키보드 포커스·클릭으로 열고, 모바일에서도 터치로 확인합니다. 클릭하면 열린 상태를 유지하며 다시 클릭하거나 Escape 키로 닫습니다. 연간 결과에서는 안내를 한 번만 제공합니다. 출생시간 확인 필요 배지와 결과 보류 표시는 유지하며, 인쇄 및 JSON에는 안내 원문을 보존합니다.
